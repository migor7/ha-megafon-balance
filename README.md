# Мегафон: баланс для Home Assistant

Неофициальная интеграция Home Assistant: баланс SIM-карт МегаФона из личного кабинета [lk.megafon.ru](https://lk.megafon.ru). Показывает баланс номера, под которым вы входите, и всех номеров, привязанных к нему в кабинете («Мультиаккаунт»).

> Интеграция не связана с ПАО «МегаФон» и не поддерживается им. Она пользуется тем же неофициальным API, что и мобильное приложение и веб-кабинет, и может перестать работать, если МегаФон его поменяет.

## Сделано вайб-кодингом

Интеграция целиком написана вайб-кодингом: код писал ИИ-ассистент **Claude** (Anthropic) по описанию задачи. Человек ставил задачи, проверял результат на своём Home Assistant и приносил ошибки из журнала. Порядок запросов к кабинету подсмотрен у провайдера МегаФона для [AnyBalance](https://github.com/dukei/any-balance-providers).

Ошибки и предложения — в [Issues](https://github.com/migor7/ha-megafon-balance/issues), желательно со строками журнала.

## Установка

### Через HACS
1. HACS → меню (⋮) → **Пользовательские репозитории**.
2. Репозиторий: `https://github.com/migor7/ha-megafon-balance`, тип: **Integration**.
3. Найдите «Мегафон: баланс», установите и перезапустите Home Assistant.

### Вручную
Скопируйте папку `custom_components/megafon_balance` в `config/custom_components/` и перезапустите Home Assistant.

Нужен Home Assistant **2024.11** или новее. Иконка из папки `brand/` показывается начиная с **2026.3**.

## Настройка

**Настройки → Устройства и службы → Добавить интеграцию → «Мегафон: баланс».** Введите номер телефона (10 цифр, можно с +7 или 8) и пароль от личного кабинета. Пароль задаётся в кабинете или командой `*105*00#`.

Для каждого номера появляется устройство «Мегафон +7 …» с сенсором **Баланс** (₽). В атрибуте `available_with_limit` — сумма с учётом кредитного лимита, если он есть. Номера, привязанные в кабинете позже, появляются сами при следующем опросе.

### Расписание опроса

**Настройки → Устройства и службы → Мегафон: баланс → «Настроить»:**
- **Общее расписание** — для всех номеров: раз в N часов или раз в N дней в заданный час (от раза в час до раза в месяц). По умолчанию — раз в 6 часов.
- **Своё расписание для номера** — отдельное расписание для любого номера; остальные идут по общему.

## Как интеграция бережёт аккаунт

- Если МегаФон отказывает во входе, просит капчу или временно блокирует, интеграция делает паузу перед следующей попыткой: 1, 3, 6, 12, затем 24 часа. Пауза сохраняется на диске и переживает перезагрузку Home Assistant.
- При запуске Home Assistant интеграция не повторяет вход каждые несколько секунд: сенсоры появятся после первого успешного опроса.
- **Капча:** войдите один раз в lk.megafon.ru в браузере с этим номером, после паузы интеграция войдёт сама.
- **Неверный пароль:** Home Assistant попросит ввести его заново.
